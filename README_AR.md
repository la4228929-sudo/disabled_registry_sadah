# disabled_registry_sadah

## نظام صندوق رعاية وتأهيل المعاقين - فرع صعدة

نظام متكامل لإدارة وتسجيل المستفيدين من صندوق رعاية المعاقين في محافظة صعدة باليمن، مبني بـ Python و Tkinter مع قاعدة بيانات SQLite.

## المميزات الرئيسية

✅ نظام إدارة مستفيدين متقدم
✅ واجهة رسومية احترافية بدعم اللغة العربية
✅ قاعدة بيانات SQLite موثوقة
✅ نظام تسجيل دخول وصلاحيات
✅ تقارير وإحصائيات شاملة
✅ طباعة البطاقات والسندات
✅ سجل شامل للعمليات
✅ بحث متقدم وسريع

## التثبيت والتشغيل

### المتطلبات
- Python 3.7 أو أحدث
- pip

### خطوات التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/la4228929-sudo/disabled_registry_sadah.git
cd disabled_registry_sadah
```

2. تثبيت المكتبات:
```bash
pip install -r requirements.txt
```

3. تشغيل التطبيق:
```bash
python main.py
```

## جداول قاعدة البيانات

### 1. users - المستخدمون
- إدارة حسابات المستخدمين والصلاحيات

### 2. disabled_people - المستفيدون
- البيانات الرئيسية للمستفيدين (34 حقل)

### 3. disabilities_list - الإعاقات الفرعية
- تفاصيل الإعاقات لكل مستفيد

### 4. needs_list - الاحتياجات
- رصد الاحتياجات الميدانية

### 5. provided_services - الخدمات المقدمة
- الخدمات والمساعدات المقدمة

### 6. service_vouchers - سندات الخدمة
- سندات طلب الخدمة والأجهزة التعويضية

### 7. attachments - المرفقات
- المرفقات والوثائق

### 8. system_logs - سجل النظام
- سجل حركة النظام والعمليات

## الوحدات الرئيسية

### Database Module
إدارة الاتصال بقاعدة البيانات والاستعلامات

### Services Module
- `DisabledPersonService`: إدارة المستفيدين
- `DisabilityService`: إدارة الإعاقات
- `NeedService`: إدارة الاحتياجات
- `ServiceVoucherService`: إدارة السندات

### Reports Module
- توليد تقارير HTML
- توليد ملفات Excel
- طباعة البطاقات

## الواجهات الرئيسية

1. **نافذة تسجيل الدخول** - تسجيل الدخول الآمن
2. **الشاشة الرئيسية** - واجهة العمل الرئيسية
3. **واجهة البيانات والاستمارات** - إضافة وتعديل البيانات
4. **نافذة الاحتياجات** - إدارة احتياجات المستفيدين
5. **نافذة الخدمات** - تسجيل الخدمات المقدمة
6. **نافذة التقارير** - إنشاء التقارير والإحصائيات

## أنواع المستخدمين والصلاحيات
